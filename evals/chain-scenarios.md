# Sequential Chain Scenarios

## C01 - Research claim to forecast

Start with a vague claim that remote work reduces innovation. Run framing, evidence, scale, mechanism, dynamics, and forecast in order. Each module consumes the previous record and creates a child version.

## C02 - Organization diagnosis to finite choice

Analyze delayed delivery in a team. Run framing, evidence, human, mechanism, dynamics, choice, and audit. The final result must include inaction and must not create authorization.

## C03 - Public policy high-impact judgment

Analyze a proposed automated eligibility rule. Run framing, evidence, scale, human, choice, and audit. Missing affected-party input must lower the output ceiling.
